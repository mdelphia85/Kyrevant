# Kyrevant

Unity 6.5 / URP real-time 3D gameplay prototype.

## Overview

Kyrevant is an original sci-fi/fantasy gameplay prototype built in Unity and C#, developed to demonstrate real-time 3D gameplay systems, player control, camera systems, combat, enemy behavior, and scalable game architecture.

## Current Systems

- Third-person player controller
- WASD movement
- Gravity and jumping
- Camera orbit and follow
- Camera-relative movement
- Player rotation
- Combat and attack system
- Enemy detection
- Health and damage system
- Enemy death system

## Technology

- Unity 6.5
- Universal Render Pipeline (URP)
- C#
- Unity Input System
- Character Controller
- Git / GitHub

## Controls

| Input | Action |
|---|---|
| W / A / S / D | Move |
| Mouse | Camera |
| Space | Jump |
| Left Mouse | Attack |

## Architecture

The project is organized into separate systems for core management, player control, camera, combat, AI, and future gameplay systems.

## Roadmap

Future development will expand Kyrevant into a larger RPG/RTS hybrid featuring advanced AI, factions, abilities, inventory, strategic systems, and additional world systems.

## Purpose

This project demonstrates practical Unity and C# development, real-time 3D gameplay programming, debugging, and system-oriented architecture.
